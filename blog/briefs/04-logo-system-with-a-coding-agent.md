## Angle
A coding agent can draw SVG, render it, look at the result and fix it, and that loop (not any single
prompt) is what made the set good. Tell it as a process with the mistakes included.

## Facts to use (from the design session; do not add to them)
- Starting point: nine products, early drafts from image generators, mixed styles.
- Research said the same few things: one shape language, a small palette, test at 16px, in one
  colour and on dark grounds, and treat the background as a variant, not part of the mark.
- Decision: one construction for every product, a rounded-square tile in the product colour, a cream
  glyph of solid shapes, one accent, no outlines or gradients. Scenes add a soft disc behind the subject.
- The loop: write SVG, render with Playwright, look, fix. Several things failed on first look:
  the capybara read as a hamster, the cuttlefish read as a jellyfish and then as a fish with a tail,
  the kopi pot read as a watering can, the satay skewer tip read as a pencil, stripes on the cuttlefish
  made it look like a grub.
- Variants: tile icon, full-bleed square for avatars, one-colour mono with true holes. The favicon is a
  bare transparent glyph that changes colour for dark tabs, and the touch icon is opaque and full-bleed.
- The fraktal frond is generated by a seeded script (`fern.py`), so the logo is a seed.
- Honest limit: these are hand-built SVGs. For print, refine silhouettes in Inkscape or Figma.
