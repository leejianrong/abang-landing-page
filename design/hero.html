Durable Python that shows its work.

Write ordinary async Python. Satay records every step to an append-only journal, survives crashes, and replays exactly what happened — then shows you the whole run locally in Satay Studio. No graph DSL, no hosted service.

enrich.py
import satay

@satay.task(retries=3)
async def fetch(url: str) -> dict:
    # your I/O, your SDK calls
    ...

@satay.workflow
async def enrich(urls: list[str]) -> Report:
    pages = await satay.map(fetch, urls, concurrency=8)
    draft = await summarize(pages)
    ok    = await satay.wait_for_event(Approval, key="review")
    return await publish(draft) if ok else draft
